# bittype/ACX-002 — Generation assembly escaped the kernel

**Status** Corrected and qualified in the generation implementation.

The composer already selected individual type mappings and scheduled definitions. Its input was a complete Composition built by a factory outside the kernel. Each of the four Horos-to-native factories constructed its own source, target and bindings, chose roots, and supplied invocation policy. A consumer changing one list representation had to mutate the setup assembled by that factory or assemble the complete pipeline itself. Across the four targets, request and admission policy could drift independently. See the [previous TypeScript factory](https://github.com/Bitspark/bittype/blob/b82afd1a2b2637d48ead005c9a1aea55040aa16f/generation/syntax/composition/horos-to-typescript/go/defaults.go).

**Rules.** AC-02 assigns representation meaning to its owner and shared invocation guarantees to the kernel. AC-03 requires adding an independently supplied case to change only its implementation and the consuming selection. AC-05 requires construction to preserve identity, scope and failure guarantees. A working pagination output checked the selected representation but could not establish who owned the assembly. [Architectural correctness rules](https://github.com/Bitspark/platform/blob/main/docs/concepts/architectural-correctness.md#numbered-rules)

**Correction.** Consumers supply separate source, target and mapping libraries; requests name evidence, roots and a generation profile. The kernel authenticates roots and receipts, selects descriptions and freezes their composed native program before construction. An override names its exact selector and both provider-qualified binding IDs. The owning mapping describes child representations; the kernel authenticates their scope. The four complete-pipeline factories and their presets were deleted. [Construction contract](../kernel-composition.md)

**Qualification.** A consumer replaces List inside an open Page, supplies an imported Cell whose Wire body has no selected structural mapping, and receives an error with zero output on a failing replacement. The same registry accepts an unrelated source language with its own source meaning and native helper. Tests exercise foreign registrations, incompatible APIs, expired requests, concurrent invocation and explicit root selection. These results concern generation. The [verification composition case](0001-verification-composition.md) has its own status.
